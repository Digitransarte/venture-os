# Venture OS — Development Instructions

## Purpose

Build a practical AI-assisted system for developing business ideas
from exploration to execution.

## Stack

- Python
- Streamlit
- SQLite
- SQLAlchemy
- Pytest

## Development principles

- Prefer simple and reversible implementations.
- Do not add dependencies without justification.
- Preserve separation between facts, assumptions and decisions.
- Keep project state in structured database records.
- Keep system documentation in Markdown.
- Run tests after material changes.
- Never commit secrets or .env files.

## Product principles

- Complexity belongs inside the system.
- The interface must remain simple.
- Every workflow must lead to a result, decision or next action.
- Do not create functionality without an identified user need.
